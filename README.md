## Requirements and usage

- Use JDK 8 or newer for the Java 8 examples.
- Some later sections demonstrate features introduced after Java 8 and require the corresponding newer JDK.
- The examples are organized by course section under `src` and are intended to be compiled and run individually.
- This branch does not use a shared Maven or Gradle build because the examples are independent learning snippets.

Generated `.class` files and IDE-specific metadata are intentionally excluded from version control. Compile source files into a separate output directory when revisiting an example, for example:

```powershell
javac -d out path\to\Example.java
java -cp out package.name.Example
```

## Repository structure

This `java8` branch covers modern Java and reflection. The repository's other learning areas are maintained in the `java`, `collections`, `multithreading`, `spring`, and `mongodb` branches, while `main` provides the top-level index.
