# Java Developer Learning Codebase

This repository is a personal learning and revision archive for Java, collections, modern Java features, concurrency, Spring, and MongoDB. It is organized with one topic per branch rather than keeping all unrelated examples in `main`.

## Topic branches

| Branch | Contents |
| --- | --- |
| [`java`](https://github.com/amit-vishwa/java-codebase/tree/java) | Core Java, introductory DSA, I/O, JDBC, and language fundamentals |
| [`java8`](https://github.com/amit-vishwa/java-codebase/tree/java8) | Streams, lambdas, functional programming, later Java features, and reflection |
| [`collections`](https://github.com/amit-vishwa/java-codebase/tree/collections) | Lists, sets, queues, maps, iterators, streams, and concurrent collections |
| [`multithreading`](https://github.com/amit-vishwa/java-codebase/tree/multithreading) | Threads, synchronization, executors, futures, parallel streams, and asynchronous programming |
| [`spring`](https://github.com/amit-vishwa/java-codebase/tree/spring) | Introductory Spring IoC and dependency-injection examples |
| [`mongodb`](https://github.com/amit-vishwa/java-codebase/tree/mongodb) | A Spring Boot and Spring Data MongoDB tutorial API |

Select a branch before cloning or browsing its code. Each branch has its own README with prerequisites, scope, and usage instructions.

## Purpose and status

This is a historical educational repository, not one deployable application. Examples come from different learning periods, use different Java versions, and should be run independently. The repository is useful for personal revision but is not presented as a polished portfolio project.

No branch should contain real user data, production credentials, or private API keys. Use environment variables and synthetic data when an exercise requires a database or external service.

## Recommended learning order

1. `java`
2. `collections`
3. `java8`
4. `multithreading`
5. `spring`
6. `mongodb`

The separate `dsa` repository contains the larger algorithm and data-structure collection, while more complete Spring projects are maintained in their own repositories.
