# overview 
This repo has the code for collection framework related topics of Java

i. Java Collections Framework Complete
- This repo has the code for complete collections framework in Java
- Youtube course link - https://www.youtube.com/playlist?list=PLA3GkZPtsafZZsLj0Tybu3y0HVl-hp1ea

ii. Java Collections from basics to Advanced
- This repo has the code from basics to advanced collections framework concepts of Java
- Udemy course link - https://qube.udemy.com/course/collections-and-concurrent-collection-video-lectures-and-tutorials/learn/lecture/13940710#overview

## Topics covered

- Lists, sets, queues, deques, and maps
- Comparable and comparator ordering
- Iterators and collection traversal
- Concurrent collection implementations
- Java 8 streams, collectors, functional interfaces, and method references

## Requirements and usage

- JDK 17
- Maven 3.8 or newer

Build the examples from the `collections` directory:

```powershell
Set-Location collections
mvn test
```

The examples are independent learning snippets. Run an individual class through its `main` method when revisiting a topic. Generated build output and IDE-specific settings are excluded from version control.

## Repository structure

This `collections` branch contains Java collection and stream exercises. Other learning areas are maintained in the `java`, `java8`, `multithreading`, `spring`, and `mongodb` branches, while `main` provides the top-level index.
